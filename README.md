# نور — NOOR · EASY CODE

مصحف رقمي بالخط العثماني، يعمل بدون إنترنت.

- 604 صفحة مصحف حقيقية (تخطيط المدينة) مع فواصل السور والبسملة وأرقام الآيات
- عرض آية + ترجمة: ru, en, fr, es, tr, ur, id, zh, bn, sv (10 لغات)
- واجهة بـ8 لغات (ar, en, ru, fr, es, tr, ur, id) مع اتجاه تلقائي
- 4 مظاهر: ليلي، نهاري، ورقي، زمردي + حجم خط واختيار الخط
- بحث ذكي في النص العثماني وبدون تشكيل، وبحث في الترجمة
- محفوظات، متابعة القراءة، وتقدم الختمة (604 صفحة)
- PWA: تثبيت على الشاشة الرئيسية وعمل أوف لاين كامل
